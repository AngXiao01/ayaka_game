# 雪见茶会与多出来的客人

> 用 `STORY=duval` 启动（`python3 main.py` 或 `python3 web/server.py`），存档默认叫 `duval`。内容在 `stories/duval/`，和默认的 `content/` 互不影响。
> 下面「一到六」是作者写的剧情；最后的「实现说明」是把它放进引擎时做的取舍。

## 一、人物

| 人物 | 要点 |
|---|---|
| 绫华 | 茶会主人，礼数周全，不愿让任何一位客人难堪 |
| 托马 | 负责操办茶会的杂务 |
| 塞莱斯汀·杜瓦尔 | 枫丹画家。短发，穿旅行装，手指上沾着颜料。不懂茶道，但爱问 |
| 旅行者 | 受邀的客人 |
| 派蒙 | 受邀的客人。第一次收到写着自己名字的请帖，高兴了好几天 |
| 豆吉 | 镇守之森的小狸猫，好奇心重 |
| 老狸猫 | 林子里年纪最大的狸猫，识字，但对外面世界的印象停在几十年前 |

狸猫的规矩：变身时头上要顶一片叶子，叶子一掉就会变回原形。

## 二、前情

锁国令解除后的第一个秋天，杜瓦尔女士来到稻妻，住在离岛画画。绫华在社奉行的文书里看到她附上的速写，很是喜欢，便请她初雪后来屋敷参加一场小小的雪见茶会。两人此前从未见过面。

茶会只请三位客人：杜瓦尔女士、旅行者、派蒙。

茶会前三天，托马写请帖，把杜瓦尔女士那张的家纹盖反了。他重写了一张送去离岛，盖坏的那张随手扔进后门外的纸篓。

豆吉在纸篓里翻到了这张帖子。纸面讲究，又盖着家纹，它觉得新奇，就叼回林子去问老狸猫。老狸猫念给它听："神里家请一位枫丹来的女士喝茶。"末了还补了一句："枫丹的女人，都戴插羽毛的大帽子，穿蓬蓬裙。"

茶会是什么，枫丹女士又是什么样，豆吉都没见过。它越想越好奇，决定变成枫丹女士，自己进去看看。

## 三、茶会前三天（可选）

玩家如果提前来屋敷，可以看到这些事：

| 时间 | 事件 |
|---|---|
| 第 1 天 | 托马发现纸篓里那张请帖不见了。后门外的雪地上有一串小爪印，旁边落着一根染过色的鸡毛 |
| 第 2 天 | 爪印变成了后腿站立行走的样子。巡夜的家仆说，看见一顶大帽子从林边飘过去，帽子底下没有人 |
| 第 2 天夜 | 玩家若守在后门，能看见一只狸猫顶着叶子，对着结冰的水洼练屈膝礼，最后被帽子整个扣在底下 |
| 第 3 天 | 茶会当天 |

## 四、茶会当天

**迎客**

豆吉在镇守之森里领着杜瓦尔女士绕了几圈，自己抢先到了屋敷。它头戴插三根羽毛的宽檐帽，身穿裙摆蓬得能塞进一张矮桌的长裙，手里摇着扇子，进门就说："日安，吾乃杜瓦尔。"

半个时辰后，真正的杜瓦尔女士才到。她一边拍外套上的落叶一边说："你们的林子，路好像会自己转圈。"

两位杜瓦尔撞了个正着，在场谁也没见过真正的她。绫华不愿失礼，把两位都请了进去。

托马收请帖时发现不对：发出去三张，手里却有四张，其中一张的家纹是反的。他认了出来："这是我扔掉的那张。"

**席间的破绽**

| 环节 | 真画家 | 狸猫 |
|---|---|---|
| 打扮 | 一身简便的旅行装。看见对方的帽子，小声说："我祖母那一辈才这么穿。" | 一身几十年前的枫丹时髦打扮 |
| 进茶室 | 茶室入口只有半人高，她摘了帽子再钻进去 | 帽子卡在入口，它侧着身硬挤进去，坚称"枫丹淑女从不摘帽" |
| 吃点心 | 端着栗子羊羹，先问该怎么吃 | 一口吞下，又趁人不注意往袖子里塞了一块 |
| 画雪景 | 画庭院、石灯笼和积雪 | 画的全是膝盖那么高的视角：榻榻米边、大家的脚、点心盘底 |
| 跪坐 | 坐不惯，悄悄换了好几次姿势 | 坐得笔直，只有裙摆底下鼓起的一块偶尔会动 |

找到两处破绽后，玩家就可以行动了。

## 五、结局

| 选择 | 结局 |
|---|---|
| 当众揭穿 | 被指认的那位杜瓦尔慌忙起身，帽子一歪，叶子飘落下来。豆吉"砰"地变回原形，帽子正好扣在它头上。它抱着请帖从廊下逃回了森林 |
| 让派蒙撞掉帽子 | 派蒙"不小心"从它头顶飞过，把羽毛帽撞飞，叶子跟着落了下来。豆吉当场现形，满座大笑。托马追着滚走的帽子跑了半个屋敷 |
| 私下告诉绫华 | 绫华不点破，茶会照常进行到最后。散席后，她单独留下这位客人，在廊下问："您真正的名字是什么？"然后重写了一张请帖，在收件处写上它的名字，交给它。杜瓦尔女士在一旁把这一幕画了下来。如果玩家看过第 2 天夜里那一幕，豆吉还会补一句："那个弯腰的礼，我练了两个晚上。" |

如果玩家认错了人，杜瓦尔女士会笑着摘下帽子给大家看，帽子底下没有叶子。剧情随后转入"让派蒙撞掉帽子"的结局。

## 六、收尾

第二天一早，托马在后门外发现一个用落叶包着的小包。里面是一捧镇守之森的栗子，还有那张盖反了家纹的请帖，背面按着一个小小的爪印。

开春后，杜瓦尔女士回了枫丹。她带回去的那幅雪景里，茶席末座多出一位戴宽檐羽毛帽的小个子客人，正把一块羊羹往袖子里塞。

## 实现说明（把上面放进引擎时的取舍）

**怎么映射**
- 地点只有三处：神里屋敷（茶室的五处破绽都是屋敷里的「查看」物件）、镇守之森（老狸猫、被折过的叶子）、离岛（真画家平时住的地方）。
- 第 3 天午后茶会开席（一个议程立起 `party_open`）：豆吉变的客人先到；半个时辰后真画家到（议程 `duval_arrives`，不算路上的时间）。两位的显示名只写外观——「杜瓦尔女士（旅行装）」「杜瓦尔女士（羽毛帽）」——不泄漏谁是真的。
- 五处破绽 = 五个「查看」物件，开席前只是普通的入口和座垫，开席后才能看到客人的举止。找到其中**任意两处**（`any_min: 2`），就能悄悄告诉绫华，进入收场一幕。
- 收场四个提议：当众指认羽毛帽（对）、当众指认旅行装（错，转入派蒙结局并多一段「认错了人」）、私下告诉绫华（和绫华商量）、让派蒙撞掉帽子（和派蒙商量）。不做任何一个就是「无人点破」。
- 第 2 天夜里的练礼那一幕是一个议程目击：玩家守在后门（用「蹲守」守到夜晚）才看得到，会得到一条线索和一个标记，私下结局里豆吉会补那句台词。
- 老狸猫是一条可选的捷径：带着至少两样茶会前的痕迹去问，他会把来龙去脉讲出来。

**原文里没交代、这里补上的几处**
1. **托马怎么知道哪张请帖是谁的？** 他收请帖时，客人是自己把它放进同一个漆托盘里的，他当时在招呼人，没留意是谁放的。否则一看就知道谁是假的。
2. **提前来屋敷的人该做什么？** 加了「纸篓里不见了的请帖」「雪地上的爪印」「后腿站直的印子」「飘过林边的大帽子」「练屈膝礼的小狸猫」「被折过的叶子」这几条茶会前的线索；它们不是必需的，但会让茶会上的破绽更好认。
3. **真画家在茶会前的两天在哪？** 离岛，玩家可以先去认识她，她会自己说出「穿旅行装、不懂礼数、画站着看到的东西」，这是后来辨认的参照。
4. **没人点破怎么办？** 茶会散席时触发「无人点破」的默认收场；之后还可以继续在稻妻走动。

**留给作者的问题**
- 真画家的「私下告诉绫华」和「当众揭穿」都需要绫华点头，这符合她的人设，但意味着玩家不能越过她直接揭穿。如果希望玩家能自己决定，要把当众指认的商量对象换成别人，或者去掉这一步。
- 豆吉的口吻（老派夸张、几十年前的枫丹印象）目前由人物卡里的几条例句和说话方式约束，真模型下表现不错，但被连续追问枫丹细节时会不会露馅，没有专门测。
