# 新剧情大纲 v3（待确认；不会被游戏加载，放在 _design 里只给人看）

> 原创设定，不是原作内容。名字已定：茶碗「月白」；神龛里的白狐长辈不起名，称「稻荷社的守夜狐」。

## 一句话

**两件事撞在了一起：一只狸猫偷零嘴，一只老狐狸在悄悄报恩。** 平藏和所有人把它们当成一个「怪盗」。

## 一、真相

### 1. 「月白」有一道旧裂纹
神里家传了几代的白乐烧茶碗，绫华的母亲生前最爱。碗上有一道头发丝一样细的旧裂纹，只有母亲知道。她点茶前**总要先把碗捂在手心里暖一暖，从不往里直接倒滚水**——绫华一直以为这是母亲的小习惯，其实是在护着那道裂。母亲走后没人再知道，今年雪见茶会，绫华打算照老规矩，用刚烧开的水点第一碗茶。

### 2. 守夜狐听见了
绫华的母亲年轻时在庭院的老梅树下救过一只被捕兽夹夹住的白狐，就是现在的守夜狐。这些年她每到冬天都会悄悄回那棵树下看看。最近天冷，茶室里的月白夜里偶尔发出细细的「叮」的一声——瓷器受冷要裂的声音。她听得出来：**再浇一次滚水，它就碎了，碎在茶会上，碎在绫华手里。**

### 3. 为什么是偷，不是说
- 她不能开口说：狐狸的话人听不进去，更何况她是个来历不明的老妇人。
- 更要紧的是，**报恩是狐狸的规矩：事成之前不能让恩人本人知道。** 她要的是茶会那天，碗好好地回到架子上，比以前更好，绫华只当它从没离开过。
- 修这个碗要金缮，要用狐火烘漆，要在镇守之森的神龛下，借三夜的月光和雪气。**所以必须把碗带走三夜。**

### 4. 她是怎么进去的
- 屋敷门楣上有社奉行的符印，**妖物进不去**，除非拿着盖了社奉行印的东西，当作客人。
- 她去印坊后巷，从学徒**小吉**的工位上叼走一张盖了印的请柬样张。纸边留下一个缺口和爪印。她认得小吉：这孩子每月都去神龛替师傅祈福。
- 失窃夜，她**变成小吉的模样**，手里拿着那张样张，敲屋敷后门，说落了东西。托马让「小吉」在门房等着，转身去拿灯笼。
- 她绕到茶室，兽形爬上高窗，在窗台上变回人形、取碗、拔开插销，再从窗口出去。窗台上，一道袖口灰印是人形留的；一串**细长的爪印**，外加几根**白毛**，是兽形留的。**同一个东西，不是一人一兽。**
- 她抱着白纸包着的碗走过花见坂，往林子去。阿缘看见了「小吉」：走路发飘，灯笼下耳朵好像是尖的。屋敷后墙外的泥地上，鞋印走了十几步就止住，接着是爪印往森林去。

### 5. 狸猫是另一件事
镇守之森有只胖狸猫，贪嘴爱捣乱，正巧同一晚下山：
- 木漏茶室：偷油豆腐（它的点心）、茶筅（它爱学人点茶）。
- 志村屋：叼走一叠白和纸（它爱闻墨香，也拿来垫窝）。
- 现场：**圆圆的爪印**和**棕色的短毛**。零嘴堆在神龛后的树洞里，**没有碗**。

**线索一眼可辨：狐的爪印细长、毛是白的；狸的爪印圆、毛是棕的。**

### 6. 小吉是被冤枉的
他是最后一个见过茶室的外人，样张从他工位上少了一张，阿缘说看见「小吉」抱着布包。他嘴上说那晚在家睡觉，其实是偷偷溜出去，到神龛替病中的师傅祈福——**他在林子边看见了「另一个自己」往神龛走，吓得跑回去，从此不敢说**，怕被当成疯子，更怕被当成贼。

### 7. 平藏的错
他是个讲证据的理性派，不信妖怪。他看到：窗台上有人的袖口灰印、有兽爪印和白毛；铺子的货架上是棕色短毛和圆爪印。他很快就推到「**至少是两拨**」，可他想不通窗台上**人和狐为什么在同一个地方**——他理解成「怪盗带着一只狐狸当帮手」。只有「同一个东西能变」这个答案，他的理性解释不了。

| 神龛上的白碗 | 镇守之森 黄昏/夜里 | 碗在祭台上，**裂纹已被金线补好大半**，守夜狐现身 |

**核心推理链：**
1. 毛色和爪印不同：棕毛圆爪（铺子、阿缘门口），白毛细爪（窗台）→ **两拨，不是一个怪盗**。
2. 窗台上同时有人的袖口和狐的爪，鞋印在墙外变成爪印 → **同一个东西会变**。
3. 托马见到的「小吉」样张只印了一半，印坊少了一张、纸边带爪印，阿缘说耳朵是尖的，小吉说自己看见了另一个自己 → **「小吉」是假的**。
4. 爪印和白毛往森林去，宗次看见青白灯火 → **碗在神龛**。
5. 托马听见的「叮」，加上绫华母亲点茶前先暖碗的习惯 → **碗有裂；狐狸是来修它的**。

## 三、守夜狐（新角色）

只在镇守之森、黄昏和夜里出现，且玩家已经知道狐火或狸窝才找得到。说话平和干脆，有点老派的幽默，不说谜语。认得绫华母亲，对绫华有长辈对晚辈的惦记。她**不为自己辩解**：承认拿了碗、承认借了小吉的脸，是她做得不对；但碗要再修两夜才好，她只求这两夜。最在意的是：报恩不能让恩人知道，也不想连累小吉。

## 四、结局

- **成全（最好，带「羁绊」线）：** 绫华听完事情，想起母亲先暖碗的习惯，同意等两夜，对外只说碗找到了。茶会那天它回到架子上，裂纹处一道金线。第一碗茶，她先把碗捂在手心里暖了一会儿。
- **成全（普通）：** 同上，但没有走完绫华的私人线。
- **强取：** 玩家带着没修完的碗回去。茶会上第一碗茶，滚水浇下，碗碎了。守夜狐不再出现。
- **报官：** 玩家太慢，平藏把小吉当成怪盗抓走，小吉被冤枉入狱。最糟结局。
- **来不及：** 茶会开了，碗没回来。

## 六、为什么说得通（自查清单）

| 疑问 | 回答 |
|---|---|
| 狐狸为什么不直接告诉绫华 | 人听不进去；更重要的，报恩规矩是事成之前不能让恩人知道 |
| 为什么非要把碗带走 | 金缮要狐火烘漆、神龛下的月光雪气，三夜 |
| 为什么变成小吉 | 屋敷符印拦妖物，只有带盖印样张的「客人」进得去；小吉是常来常往、门房认得的人 |
| 为什么留爪印和白毛 | 在窗台变回原形的瞬间留下的，她没想到会有人细查 |
| 狐狸为什么没立刻送回来 | 还没修完。修好前她不能让碗再受冷、受力 |
| 狸猫的事和狐狸有关吗 | 没关系，纯属巧合——「两件事撞在了一起」 |
| 小吉为什么不说自己看见了另一个自己 | 怕被当成疯子，更怕被当成贼 |
| 平藏为什么不早想到「会变」 | 他是理性派，官方也不承认妖怪；他的理论在证据面前已经走到头，只缺最后一块 |
| 绫华母亲的习惯有什么用 | 它是玩家能验证的线索：绫华自己能说出来，让玩家和她都意识到碗有裂 |
